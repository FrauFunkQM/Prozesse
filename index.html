Arbeitsblatt: Geschäftsprozesse verstehen und anwenden

🎯Lernziel: Die Schüler*innen verstehen die grundlegenden Elemente eines Geschäftsprozesses und können diese auf einen beliebigen Prozess anwenden.

📖Teil 1: Grundlagen

Was ist ein Prozess?

Ein Prozess ist eine strukturierte Abfolge von Tätigkeiten, die ein bestimmtes Ergebnis erzeugt.

Jeder Prozess hat:

  • ✓einen Startpunkt
  • ✓mehrere Schritte
  • ✓einen Endpunkt
  • ✓ein Ergebnis

Warum beschreibt man Prozesse?

Im Qualitätsmanagement ist es wichtig, dass Abläufe:

Eigenschaft Bedeutung
✓klar beschrieben Jeder versteht, was zu tun ist
✓nachvollziehbar Man kann jeden Schritt zurückverfolgen
✓wiederholbar Das gleiche Ergebnis kann erneut erzielt werden
✓überprüfbar Man kann kontrollieren, ob alles richtig läuft

Nur so kann Qualität dauerhaft gesichert werden.

🧩Teil 2: Die 7 Bausteine eines Prozesses

1. 🎯 Prozessaufgabe

Die Hauptaufgabe oder das Ziel des Prozesses

Frage: Wozu gibt es diesen Prozess?

2. 🔧 Ressourcen

Alles, was benötigt wird, um den Prozess durchzuführen:

  • • Materialien
  • • Personal
  • • Maschinen oder Geräte
  • • Hilfsmittel

Frage: Womit wird gearbeitet? Wer arbeitet?

3. 📋 Verfahren / Prozessschritte

Die Einzelschritte, die nacheinander ausgeführt werden

Frage: Was passiert Schritt für Schritt?

4. 📥 Prozesseingabe (Input)

Alles, was vorhanden sein muss, bevor der Prozess starten kann

Frage: Was muss bereitstehen, damit der Prozess beginnen kann?

5. ▶️ Startereignis

Das Ereignis, das den Prozess auslöst

Frage: Was bringt den Prozess in Gang?

6. ⏹️ Endereignis

Das Ereignis, das zeigt, dass der Prozess abgeschlossen ist

Frage: Woran erkennt man, dass der Prozess fertig ist?

7. 📤 Prozessergebnis (Output)

Das konkrete Ergebnis, das am Ende entsteht

Frage: Was kommt am Ende heraus?
